# A股选股助手（价值 + 技术 + 估值分位）

对沪深主板 A 股打分排序，列出值得关注的清单。支持三种风格：
**量化多因子（默认，经回测验证）/ 短线波段 / 长线价值**。**仅供研究参考，不构成投资建议。**

## 打分逻辑

### 综合分 = w₁ × 价值分 + w₂ × 技术分 + w₃ × 估值分位

权重随「投资风格」切换：

| 风格 | 价值 | 技术 | 估值分位 | 适用 |
|------|------|------|----------|------|
| **短线波段** | 0.15 | 0.30 | **0.55** | ≤3 个月持有，估值低位 + 反转技术 |
| **长线价值** | **0.57** | 0.31 | 0.12 | 长期持有，基本面主导（趋势式技术）|

> **短线权重由回测校准**（见下）：估值便宜最有效、反转技术为辅；年报基本面 3 个月内几乎不变，故价值面仅留小权重当质量底。

### 价值分（内部权重）
ROE(28%)、PE(20%)、PB(14%)、净利润同比(16%)、毛利率(12%)、营收同比(10%)。
- **ROE 按报告期年化**（一季报 ×4 / 半年报 ×2 / 三季报 ×4⁄3），保证跨报告期可比。
- 再乘**经营现金流质量乘数**：现金流为负 ×0.55，严重不足 ×0.75，偏弱 ×0.90，正常 ×1.0，优秀 ×1.05。

### 技术分（两层 + 方向随风格切换）
- **快照层（全市场）**：60日动量(45%) + 年初至今(30%) + 换手率(25%)。东财不通时动量字段缺失，按中性 50。
- **真实层（仅入围前 100 名，baostock 前复权日线计算，覆盖快照值）**，方向随风格：
  - **短线波段 = 反转式**（经回测校准）：奖励超跌/超卖/低位。动量(20/60) 45% + RSI 25% + 距MA20乖离 20% + 均线状态 10%；动量越低、RSI 越超卖、越在均线下方 → 分越高。
  - **长线价值 = 趋势式**：奖励温和上涨/多头排列。动量 40% + 均线 25% + RSI 15% + 乖离 12% + 波动率 8%，再 ×0.80 + 换手率活跃度 ×0.20。

### 估值分位（防追高）
baostock 取个股近 5 年 PB(pbMRQ) 历史，算当前 PB 所处百分位：越低（越便宜）分越高
（0%→100 分，100%→12 分）。仅对入围前 100 名计算。

### 建议分级
≥80 强烈关注 / ≥72 值得买入 / ≥63 可关注 / ≥50 观望 / <50 暂不推荐。

### 量化多因子（默认风格，经回测验证有选股力）
四因子**行业中性化**后横截面 z-score 等权合成，**综合分 = 入围股内分位(0-100)**：

| 因子 | 方向 | IC(横截面) | 数据 |
|------|------|-----------|------|
| 低波动 (20日) | 越低越好 | +0.094 | baostock 收盘 |
| 反彩票 (月内最大日涨) | 越低越好（避妖股）| +0.085 | baostock 收盘 |
| 中期反转 (−60日动量) | 动量越低越好 | +0.065 | baostock 收盘 |
| 价值 (1/PB，**收盘 PB**) | 越便宜越好 | +0.061 | baostock 收盘 |

**三层行业均衡 + 盘中稳定**：
1. **选池**：全市场按 **成交额分行业分层** 取 ~100 只（`select_pool`），不再按价值分预筛 → 不扎堆金融；
2. **打分**：各因子**先行业内去均值**（行业中性）再 z-score；
3. **展示**：「每行业最多 N 只」兜底分散；
4. 四因子**全用收盘数据**（价值用收盘 PB）→ 盘中重算名单不抖。

> 这几个因子在**无偏样本外回测**（含退市股、扣成本）中 IC 稳健、训练/检验同向。
> **定性见下：是『风格 edge』而非选股 alpha。**

## 回测校准与验证（backtest*.py / factor_lab.py / strategy.py）

短线权重与因子方向不是拍脑袋，而是逐层回测得来——并主动证伪了一个看似诱人的假 edge。

### 1) 单因子方向（backtest.py）
追涨式动量与未来 ~3 月收益**负相关**（动量60 −0.19、RSI −0.12）→ A 股主板强均值回归；
故技术信号改为**反转式**（奖励超跌/超卖），秩相关由 −0.15 翻正为 +0.15。

### 2) ⚠️ 幸存者偏差证伪假 edge（backtest_sf.py）
只用"今天还在的股"时，"估值低位+反转" Top20% 超额 +4.6%；**含退市股后变 −3%（反跑输）**，
"最便宜""最超跌"档反而最差（价值陷阱/接飞刀）。**原 +4.6% 几乎全是幸存者偏差幻觉。**

### 3) 正确的横截面 IC（factor_lab.py）
用每月横截面 IC（含退市+样本外+扣成本）才看清：低波动/反彩票/中期反转**确有稳健选股力**
（多空净 +9~11%/年），价值偏弱。

### 4) 纯多头落地验证（strategy.py，对多基准）—— 最终定性
组合纯多头最优档，检验期净超额：

| 基准 | 净超额/年 | 性质 |
|------|------|------|
| **同口径等权全市场** | **−2.5%** | 最干净的选股检验 → **无选股 alpha** |
| 沪深300 / 中证500 / 中证1000 | +4.6% / +3.1% / +3.3% | 可买宽基 ETF |

**结论：🟢 实用『风格 edge』，非选股 alpha。** 跑赢可买的宽基 ETF +3~5%/年（来自"等权+中小盘+
防御"风格），但对同口径等权全市场无超额（选股本身不加分）。**实用前提**：你本来就买宽基 ETF；
**风险**：大盘/高 beta 领涨时失效。因子最强的部分在空头（散户做不了）。

> ⚠️ 局限：单一样本期/抽样、未含冲击成本与停牌不可交易摩擦、未做价值面长线时点回测。
> 运行：`python strategy.py 500 20`（输出自动结论判定）。

短线权重与「反转式技术」不是拍脑袋，而是回测得来。方法：从主板抽样，时点回测各信号
与未来 ~3 个月（60 交易日）收益的相关性（复用打分函数，前复权、非重叠窗口）。

主要发现（3000+ 样本）：
- **追涨式动量与未来收益负相关**：动量60 秩相关 −0.19、技术分(追涨) −0.15、RSI −0.12——
  A 股主板 ~3 个月维度强**均值回归**，追高被套。
- **估值便宜有效**：PB 历史分位最低档平均 +7.3%/胜率 59%，最高档 +1.9%/44%。
- 改为**反转式技术**后，技术分秩相关由 −0.15 翻正为 **+0.15**，分档单调；
  「估值为主 + 反转技术为辅」的组合 Top20% 组超额约 **+4.6%**。

> ⚠️ 局限：单一回测期、用当前主板成分（有幸存者偏差）、横截面相关、未含价值面（年报难做
> 时点对齐）。是**强方向性证据**，非严格统计显著。运行：`python backtest.py [样本数] [持有日]`。

## 数据来源（多级容错）

| 类别 | 主源 → 降级链 |
|------|--------------|
| **实时快照** | 东方财富 push2 → **baostock 清单 + 腾讯行情** → 新浪财经兜底 |
| **业绩报表** | 东方财富 datacenter（自动回退到最近已披露报告期） |

> 选股范围：仅**沪深主板**（代码 60/00 开头），已排除科创板、创业板、北交所、B 股。

## 使用

### 网页版（推荐）
```bash
bash 启动.sh
```
浏览器打开 http://localhost:8501 ，左侧选「投资风格」与筛选条件 →「开始选股」。
支持下载 CSV、查看个股均线/RSI。

### 命令行版
```bash
source venv/bin/activate
python screener.py 短线波段      # 或：python screener.py 长线价值
```
打印 Top30 并导出「选股结果.csv」。

### 回测 / 因子研究脚本
```bash
python backtest.py 150 60        # 时点回测 + 训练/检验样本外
python backtest_sf.py 300 60     # 无幸存者偏差回测（含退市股）
python factor_lab.py 500 20      # 横截面因子 IC 实验室
python strategy.py 500 20        # 纯多头组合多因子，对多基准 + 自动结论判定
```
> baostock 高频拉取会被临时限流；被限时换网络/隔日重试。`strategy.py` 有磁盘缓存与超时容错。

## 安装
```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
```
依赖：`akshare`、`streamlit`、`pandas`、`numpy`、`matplotlib`、`urllib3<2`、`baostock`。

## 说明与注意

- 首次运行需联网拉取全市场数据，约 **40~90 秒**（含入围股的 baostock 历史查询）。
- **代理处理**：`net_patch.py` 已自动绕过系统/环境代理直连。若用 Clash 等的 TUN/增强模式，
  仅关「系统代理」无效，需**彻底退出代理软件**；确认 `env | grep -i proxy` 为空。
- 东方财富 push2 不通时会自动走 **baostock 清单 + 腾讯行情**（快），新浪为最后兜底。
- 业绩报表自动回退到最近一个已披露报告期；ROE 已年化处理。
- **已知局限**：
  - 真实短线技术分依赖前复权日线，对历史 <65 个交易日的**次新股**取不到，会回落到快照值（动量可能缺失）；常做次新股需另行补充数据。
  - 短线模式下入围股按「价值分」筛选，基本面较差但短线很强的票可能进不了前 100、不会被计算真实技术分（为绕开东财不通时的假动量所做的折中）。

## 更新记录

- **打分口径修正**：ROE 按报告期年化；现金流缺失不再误扣分；过滤范围收窄为沪深主板（排除创业板/科创板/北交所）。
- **行情多级容错**：东财 push2 不通时自动走「baostock 全市场清单 + 腾讯行情」，新浪兜底，解决拉取超时。
- **新增估值分位维度**：baostock 个股近 5 年 PB 历史百分位，防追高。
- **新增短线/长线风格切换**：短线模式以真实技术面主导；并用 baostock 前复权日线为入围股计算真实动量/均线/RSI/乖离/波动率，替代东财不通时的 NaN 动量。
- **修复复权 bug**：入围股历史改用**前复权**（`adjustflag="2"`）。此前用不复权，分红/送转日价格跳空会扭曲动量、均线、波动率（高送转股票尤甚）；PB 比率不受影响。
- **RSI 改为 Wilder 平滑**，与超买/超卖阈值口径一致。
- **回测校准短线模型**：新增 `backtest.py`；据回测把短线技术改为**反转式**（奖励超跌/超卖/低位），
  权重调为 价值0.15/技术0.30/估值0.55（估值为主）。
- **短线风控**：剔除停牌/无成交、规避当日涨跌停、最小成交额（流动性）下限。
- **交互改造**：拉一次全市场数据后，改筛选条件/风格/风控**即时重算**不再联网；入围精算 per-code 缓存。
- **结果表新增**真实 60日动量 / RSI / 均线状态 列。
- **无偏回测体系**：新增 `backtest_sf.py`（无幸存者偏差）、`factor_lab.py`（横截面 IC）、
  `strategy.py`（纯多头组合，对沪深300/中证500/1000/等权全市场多基准+自动结论判定）。
- **🔑 关键研究结论**：①"估值低位+反转"短线 edge 主要是**幸存者偏差幻觉**（含退市股后反跑输）；
  ②横截面看**低波动/反彩票/中期反转**确有稳健选股力；③但**纯多头组合是"风格 edge"非"选股 alpha"**
  （跑赢可买宽基 ETF +3~5%/年，源于等权+中小盘+防御风格；对同口径等权全市场无超额）。
- **新增「量化多因子」风格（默认）**：低波+反彩票+中期反转+价值 横截面 z 等权合成，综合分=入围股内分位。
- **量化模式三层行业均衡 + 盘中稳定**（最新）：
  ① 选池由"价值分 top100"改为**成交额分行业分层**(`select_pool`)，不再扎堆金融；
  ② 因子**行业中性化**（行业内去均值再 z）；
  ③ 价值因子改用**收盘 PB**、四因子全基于收盘数据 → 盘中重算名单不再抖动；
  ④ 展示层「每行业最多 N 只」兜底分散；缺因子不一票否决、无数据给明确提示。
- **UI 打磨**：靛蓝主题统一控件色；修复侧边栏深色（标题褪色/白底、折叠按钮、数字框）、
  结果表（进度条 0.x bug、建议截断）；默认核心列+「显示全部字段」开关；加载状态单一进度条+toast。
